# Miguel Morandini — Portfólio

Portfólio pessoal bilíngue (PT-BR / EN) desenvolvido com **React**, **Vite**, **TypeScript** e **Tailwind CSS**, com identidade visual Dark Tech / Esmeralda.

## Como executar localmente

```bash
npm install
npm run dev
```

## Build para produção

```bash
npm run build
```

## Onde personalizar seus dados

Todo o conteúdo (experiências, formação, certificações, projetos, links e e-mail) está centralizado em `src/data/portfolio.ts`.
